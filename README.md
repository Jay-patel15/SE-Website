## 🚀 Getting Started

### Prerequisites
- Node.js 18+ 
- npm/yarn/pnpm
- Supabase Account

### Installation

```bash
# Clone the repository
git clone <repository-url>
cd siddhi-electricals

# Install frontend dependencies
cd frontend
npm install

# Set up environment variables
cp .env.example .env.local

# Run development server
npm run dev
```

Visit `http://localhost:3000`
